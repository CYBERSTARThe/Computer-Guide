Computers

A computer is an electronic machine that processes information by following instructions called programs.

What does a computer do?

At a basic level, computers perform four major tasks: they receive input, process information, store data, and produce output.

CPU — The Processor

The CPU, or Central Processing Unit, executes instructions and performs calculations. It is one of the main components responsible for processing information inside a computer.

RAM — Temporary Memory

RAM, or Random Access Memory, temporarily stores data and programs that the computer is actively using. More RAM can allow a computer to keep more information available at the same time.

Storage

Storage devices such as SSDs and hard drives keep data even when the computer is turned off. Your operating system, applications, documents, photos, and other files are stored here.

Operating Systems

An operating system manages the computer's hardware and provides a platform for applications to run.

Common operating systems include Windows, macOS, Linux, Android, and iOS.

Hardware vs. Software

Hardware is the physical equipment you can touch, such as the CPU, keyboard, monitor, and storage drive.

Software consists of programs and instructions that tell the hardware what to do.

Programming

Programming is the process of writing instructions that a computer can understand and execute.

What is a programming language?

A programming language is a system used to communicate instructions to a computer. Examples include Python, JavaScript, Java, C, and C++.
