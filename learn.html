Computers

A computer is an electronic machine that processes information by following instructions called programs.

What does a computer do?

At a basic level, computers perform four major tasks: they receive input, process information, store data, and produce output.

CPU — The Processor

The CPU, or Central Processing Unit, executes instructions and performs calculations. It is one of the main components responsible for processing information inside a computer.

RAM — Temporary Memory

RAM, or Random Access Memory, temporarily stores data and programs that the computer is actively using. More RAM can allow a computer to keep more information available at the same time.

Storage

Storage devices such as SSDs and hard drives keep data even when the computer is turned off. Your operating system, applications, documents, photos, and other files are stored here.

Operating Systems

An operating system manages the computer's hardware and provides a platform for applications to run.

Common operating systems include Windows, macOS, Linux, Android, and iOS.

Hardware vs. Software

Hardware is the physical equipment you can touch, such as the CPU, keyboard, monitor, and storage drive.

Software consists of programs and instructions that tell the hardware what to do.

🌐 The Internet

The Internet is a worldwide network of connected computers and devices that communicate with each other using standardized protocols.

How does the Internet work?

When you visit a website, your device sends and receives data through networks. That data can travel through routers, servers, and other network equipment before reaching its destination.

IP Addresses

An IP address identifies a device or network interface on a network. It helps computers know where data should be sent.

DNS

DNS stands for Domain Name System. It translates human-readable domain names, such as example.com, into IP addresses that computers can use.

Websites and Servers

A web server stores and delivers website files. When you request a webpage, the server sends the necessary information back to your browser.

HTTP and HTTPS

HTTP is a protocol used for transferring web information. HTTPS adds encryption to help protect data exchanged between your browser and a website.

Routers

Routers help direct network traffic between different networks. Your home router can connect devices in your home network to the Internet.

🤖 Artificial Intelligence

Artificial intelligence, or AI, is a field of computer science focused on creating systems that can perform tasks that normally require human intelligence, such as recognizing patterns, understanding language, and making predictions.

How does AI learn?

Many modern AI systems use machine learning. A machine-learning system can analyze examples in data and learn patterns that help it make predictions or produce results.

Training Data

Training data is information used to develop a machine-learning model. The quality, quantity, and relevance of the data can affect how well a model performs.

Machine Learning

Machine learning is a branch of AI in which computers use algorithms to learn patterns from data rather than relying only on explicitly written rules for every situation.

Generative AI

Generative AI refers to systems that can create new content such as text, images, audio, video, or computer code based on patterns learned from data.

AI Limitations

AI systems can make mistakes. Their output can be inaccurate, incomplete, or based on limitations in their training and design. Important information should be checked against reliable sources.

AI in Everyday Life

AI is used in many areas, including search engines, recommendation systems, voice assistants, navigation, fraud detection, translation, and software development.

🔐 Cybersecurity

Cybersecurity is the practice of protecting computers, networks, applications, and data from unauthorized access, misuse, damage, or disruption.

The CIA Triad

The CIA triad is a basic cybersecurity model made up of three goals: confidentiality, integrity, and availability.

  • Confidentiality — keeping information accessible only to authorized people.
  • Integrity — protecting information from unauthorized changes.
  • Availability — keeping systems and information available when they are needed.

Authentication

Authentication is the process of verifying who a user is. Passwords, security keys, and multi-factor authentication are examples of authentication methods.

Phishing

Phishing is a social-engineering technique in which someone is tricked into revealing information or taking an unsafe action. Phishing messages can appear through email, text messages, websites, or other communication platforms.

Malware

Malware is malicious software designed to perform harmful or unauthorized actions. Examples include viruses, worms, trojans, ransomware, and spyware.

Encryption

Encryption transforms readable information into a protected form using a cryptographic process. Authorized systems can use the appropriate key to decrypt the information.

Vulnerabilities

A vulnerability is a weakness in software, hardware, configuration, or a process that could potentially be exploited.

Basic Defense

Good cybersecurity practices include using strong unique passwords, enabling multi-factor authentication, keeping software updated, backing up important data, and being careful with unexpected links and attachments.

⚙️ Technology

Technology is the use of knowledge, tools, and systems to solve problems and accomplish tasks. Modern technology combines hardware, software, networks, and data.

Hardware

Hardware is the physical part of a technological system. Examples include processors, memory, storage drives, keyboards, monitors, and phones.

Software

Software is a collection of instructions that tells a computer or device what to do. Operating systems, web browsers, games, and mobile apps are examples of software.

Databases

A database is a system used to organize, store, and retrieve information. Websites and applications can use databases to store accounts, products, messages, and other information.

Cloud Computing

Cloud computing provides computing resources over a network. These resources can include servers, storage, databases, and applications.

APIs

An API, or Application Programming Interface, provides rules that allow different software systems to communicate with each other.

Virtualization

Virtualization allows one physical computer to create simulated computers called virtual machines. A virtual machine can run its own operating system and applications.

How Modern Technology Connects

A modern application can combine many technologies. For example, a website might use a browser, network, web server, database, API, and cloud infrastructure to deliver information to a user.

Programming

Programming is the process of writing instructions that a computer can understand and execute.

What is a programming language?

A programming language is a system used to communicate instructions to a computer. Examples include Python, JavaScript, Java, C, and C++.
